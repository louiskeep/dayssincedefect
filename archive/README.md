# Archive

Earlier prototypes and dev-only pages, kept for reference. None of this is part
of the live game (that's `index.html` + `game.html` + `src/`).

- `v2.*`, `v3.*`, `v5.*`: earlier full rewrites of the game
- `index.html`, `styles.css`, `art.js`, `catalog.js`: the first prototype (inline
  SVG character art and a separate data file, since folded into `src/game.js`)
- `style-lab.html`: art-style sandbox
- `place.html` / `place.js`: shelf placement experiment
- `gallery.html`, `bobbleheads.html`: early art viewers
- `regen-review.html`, `tech-review.html`: review harnesses used while generating art

Links between these files point at their old sibling paths, so some will 404 now
that the live files moved to `src/`. That's expected.
